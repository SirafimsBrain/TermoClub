# Правила проекта TermoClub

- README.md вести и обновлять только на английском языке.
- Первая строка каждого файла `*.py` — комментарий с полным путём от корня проекта (например, `# ghostty_wrapper/main.py`).
- UI-слой (Flet) работает только через стандартизированный интерфейс `TerminalController` и не знает о конкретных терминалах (Ghostty / Kitty и т.д.).
- Реализации терминалов живут в `ghostty_wrapper/core/terminal/<term>/`. Добавление нового терминала = реализация интерфейса + регистрация в фабрике, без изменений в UI.
- `open_new_tab` — обязательная часть контракта `TerminalController`.
- Всё важное логируется через централизованный логгер (`ghostty_wrapper/logging_setup.py`): выбор терминала, вызовы `open_new_tab` / `open_new_window`, ошибки платформенных вызовов.
